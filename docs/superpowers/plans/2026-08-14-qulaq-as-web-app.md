# Qulaq As Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `qulaq-as/` React app — reads the 42-file A1 English corpus, speaks it aloud (Web Speech API), tracks progress + spaced repetition in `localStorage`, and adds a self-checking Course Mode (Word → Collocation → Sentence → True/False Q&A) plus per-word cross-referenced usage recommendations.

**Architecture:** Vite + React 19 SPA, react-router-dom for the 4 pages (Browse/Review/Course/Settings), plain Context+hooks for state (no Redux). All content is parsed client-side from raw markdown text (two interchangeable loading modes: Vite build-time glob import, or runtime `fetch`), so every downstream feature — TTS, SRS, Course Mode, word cross-referencing — operates on the same in-memory parsed data shape, no backend.

**Tech Stack:** Vite 7, React 19, react-router-dom 7, Vitest (unit tests for the pure `lib/` parsing/logic modules only — see Global Constraints).

## Global Constraints

- New project lives at repo root: `qulaq-as/` (sibling to `exercise-formik/`, `projects/166/`), same Vite+React scaffold shape (`package.json`, `vite.config.js`, `eslint.config.js`, `index.html`, `src/`, `public/`).
- No backend, no deployment config, no user accounts — everything runs client-side via `npm run dev`.
- Per the approved spec (`docs/superpowers/specs/2026-08-14-qulaq-as-web-app-design.md` §10): **no test suite for UI (pages/hooks/components) — verify those manually**, matching this repo's sibling-exercise convention. Exception: the pure-logic modules in `src/lib/` (`parseVocab.js`, `parseProduction.js`, `srs.js`, `falseAnswerGen.js`, `wordIndex.js`) get real Vitest unit tests — they're deterministic pure functions processing ~1433 words / ~327 prompts where a silent bug would corrupt data across the whole app, and Vitest is a one-dependency addition to an already-Vite project. This is a deliberate scope split, not blanket TDD.
- Source markdown lives in `ios-project-practices/english-language-a1-c2/01-a1-temelbaslar/` (absolute path on this machine: `/Users/frontend/workspace/ios-project-practices/english-language-a1-c2/01-a1-temelbaslar/`) — 42 files, never edit them from this app; only read/copy.
- All UI-facing Azerbaijani text (labels, buttons) must render correctly — the source corpus uses `Ə/ə` (U+018F/U+0259); never introduce the Latin lookalikes `Ɛ/Ɔ` (a recurring corruption bug in the source project) when writing any Azerbaijani string into code.
- Azerbaijani strings in code/JSX must be written directly as UTF-8 source (not HTML entities), matching how the source `.md` files are written.

```js
// qulaq-as/src/lib/parseVocab.js

/**
 * Parses one of the 33 vocabulary/register .md files (01-33) into a
 * structured topic object.
 *
 * @param {string} rawText - the raw markdown file content
 * @param {string} topicId - filename without extension, e.g. "07-is-ve-peseler"
 * @returns {{ topicId: string, title: string, words: Array<{word: string, gloss: string, sentences: Array<{en: string, az: string}>}> }}
 */
export function parseVocabFile(rawText, topicId) {
  const lines = rawText.split('\n')

  let title = topicId
  for (const line of lines) {
    if (line.startsWith('# ')) {
      title = line.slice(2).trim()
      break
    }
  }
  // Strip the trailing " (English Title)" parenthetical, if present.
  const azTitle = title.split(' (')[0].trim()

  const words = []
  let i = 0
  const wordLineRe = /^\*\*(.+?)\*\* — (.+)$/

  while (i < lines.length) {
    const trimmed = lines[i].trim()
    const match = trimmed.match(wordLineRe)
    if (match) {
      const word = match[1].trim()
      const gloss = match[2].trim()
      const sentences = []
      let j = i + 1
      while (j < lines.length && lines[j].trim().startsWith('- ')) {
        const sentenceLine = lines[j].trim().slice(2).trim()
        const sepIdx = sentenceLine.indexOf(' — ')
        if (sepIdx !== -1) {
          sentences.push({
            en: sentenceLine.slice(0, sepIdx).trim(),
            az: sentenceLine.slice(sepIdx + 3).trim(),
          })
        }
        j++
      }
      words.push({ word, gloss, sentences })
      i = j
    } else {
      i++
    }
  }

  return { topicId, title: azTitle, words }
}
```

- [ ] **Step 3: Write the implementation**

Note the target-answer line's English sentence can itself contain an em-dash (`"He's a lawyer — he helps..."`), so the parser must locate the **last** `"` before the ` — ` + Azerbaijani + ` *(target)*` tail, not split naively on every em-dash.

```js
// qulaq-as/src/lib/parseProduction.js

const SECTION_RE = /^## (?:Mövzu|Bölmə \d+): (.+)$/
const SITUATION_RE = /^\*\*Situasiya:\*\* (.+)$/
// Captures: 1) EN answer (inside quotes, may itself contain " — "),
// 2) AZ translation, 3) target word/phrase.
const ANSWER_RE = /^\*\*Nümunə cavab:\*\* "(.+)" — (.+?) \*\((.+)\)\*$/

/**
 * Parses one of the 9 Active Production .md files (34-42) into topic
 * sections, each holding its Situasiya/Nümunə cavab prompts.
 *
 * @param {string} rawText
 * @param {string} fileId - filename without extension
 * @returns {{ fileId: string, sections: Array<{ topicName: string, prompts: Array<{situation: string, answerEn: string, answerAz: string, targetWord: string}> }> }}
 */
export function parseProductionFile(rawText, fileId) {
  const lines = rawText.split('\n')
  const sections = []
  let current = null
  let i = 0

  while (i < lines.length) {
    const line = lines[i].trim()

    const sectionMatch = line.match(SECTION_RE)
    if (sectionMatch) {
      current = { topicName: sectionMatch[1].trim(), prompts: [] }
      sections.push(current)
      i++
      continue
    }

    if (current) {
      const situationMatch = line.match(SITUATION_RE)
      if (situationMatch) {
        const situation = situationMatch[1].trim()
        // The answer line follows within the next couple of lines (after
        // "**Sənin cavabın:** ___").
        let j = i + 1
        let answerLine = null
        while (j < lines.length && j < i + 4) {
          const candidate = lines[j].trim()
          if (candidate.startsWith('**Nümunə cavab:**')) {
            answerLine = candidate
            break
          }
          j++
        }
        if (answerLine) {
          const answerMatch = answerLine.match(ANSWER_RE)
          if (answerMatch) {
            current.prompts.push({
              situation,
              answerEn: answerMatch[1].trim(),
              answerAz: answerMatch[2].trim(),
              targetWord: answerMatch[3].trim(),
            })
          }
        }
        i = j + 1
        continue
      }
    }

    i++
  }

  return { fileId, sections }
}
```

```js
const RATING_MULTIPLIERS = { hard: 1.2, good: null /* uses card.ease */, easy: 3.5 }

function addDays(dateStr, days) {
  const d = new Date(dateStr + 'T00:00:00Z')
  d.setUTCDate(d.getUTCDate() + days)
  return d.toISOString().slice(0, 10)
}

/**
 * A fresh SRS card, due immediately (today).
 * @param {string} today - "YYYY-MM-DD"
 */
export function createCard(today) {
  return { interval: 0, ease: DEFAULT_EASE, due: today, reps: 0 }
}

/**
 * Applies a review rating to a card and returns the updated card.
 * Does not mutate the input.
 *
 * @param {{interval: number, ease: number, due: string, reps: number}} card
 * @param {'again'|'hard'|'good'|'easy'} rating
 * @param {string} today - "YYYY-MM-DD"
 */
export function reviewCard(card, rating, today) {
  if (rating === 'again') {
    return { interval: 1, ease: card.ease, due: addDays(today, 1), reps: 0 }
  }

  const baseInterval = Math.max(card.interval, 1)
  const multiplier = rating === 'good' ? card.ease : RATING_MULTIPLIERS[rating]
  const newInterval = Math.max(1, Math.round(baseInterval * multiplier))

  return {
    interval: newInterval,
    ease: card.ease,
    due: addDays(today, newInterval),
    reps: card.reps + 1,
  }
}

/**
 * @param {{due: string}} card
 * @param {string} today - "YYYY-MM-DD"
 */
export function isDue(card, today) {
  return card.due <= today
}
```

```js
// qulaq-as/src/lib/falseAnswerGen.js

/**
 * Builds the Course Mode stage-4 True/False deck for one production file's
 * sections: one "doğru" card per real (situation, answer) pair, plus one
 * "yanlış" card per prompt pairing its situation with a DIFFERENT prompt's
 * answer (preferring a prompt from a different topic section, so the
 * mismatch is semantically obvious rather than two near-identical
 * greetings both accepting a similar answer).
 *
 * @param {Array<{topicName: string, prompts: Array<{situation: string, answerEn: string, answerAz: string, targetWord: string}>}>} sections
 * @param {() => number} randomFn - injectable RNG (defaults to Math.random) for deterministic tests
 * @returns {Array<{situation: string, answerEn: string, answerAz: string, isTrue: boolean}>}
 */
export function buildTrueFalseDeck(sections, randomFn = Math.random) {
  const allPrompts = sections.flatMap((section) =>
    section.prompts.map((prompt) => ({ ...prompt, topicName: section.topicName }))
  )

  const cards = []

  for (const prompt of allPrompts) {
    cards.push({
      situation: prompt.situation,
      answerEn: prompt.answerEn,
      answerAz: prompt.answerAz,
      isTrue: true,
    })

    const otherTopicPrompts = allPrompts.filter((p) => p.topicName !== prompt.topicName)
    const pool = otherTopicPrompts.length > 0
      ? otherTopicPrompts
      : allPrompts.filter((p) => p !== prompt)

    const mismatch = pool[Math.floor(randomFn() * pool.length)]
    cards.push({
      situation: prompt.situation,
      answerEn: mismatch.answerEn,
      answerAz: mismatch.answerAz,
      isTrue: false,
    })
  }

  return shuffle(cards, randomFn)
}

function shuffle(array, randomFn) {
  const result = [...array]
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(randomFn() * (i + 1))
    ;[result[i], result[j]] = [result[j], result[i]]
  }
  return result
}
```

```js
// qulaq-as/src/lib/wordIndex.js

/**
 * Cross-references every word against the whole corpus: every vocab
 * headword's own topic, every OTHER topic's example sentences that happen
 * to contain that word, and every Active Production answer that contains
 * it. Built once at load time; pure function of the already-parsed data,
 * no new content authoring.
 *
 * @param {Array} vocabTopics - array of parseVocabFile() results
 * @param {Array} productionFiles - array of parseProductionFile() results
 * @returns {Map<string, Array<{topicId: string, topicName: string, sentence: string, sentenceAz: string, source: 'headword'|'example'|'production'}>>}
 */
export function buildWordIndex(vocabTopics, productionFiles) {
  const index = new Map()

  function addEntry(word, entry) {
    const key = word.toLowerCase()
    if (!index.has(key)) index.set(key, [])
    index.get(key).push(entry)
  }

  function containsWord(sentence, word) {
    const escaped = word.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
    const re = new RegExp(`\\b${escaped}\\b`, 'i')
    return re.test(sentence)
  }

  // Pass 1: headwords, and their own example sentences, in their own topic.
  for (const topic of vocabTopics) {
    for (const { word, sentences } of topic.words) {
      addEntry(word, {
        topicId: topic.topicId,
        topicName: topic.title,
        sentence: sentences[0]?.en ?? '',
        sentenceAz: sentences[0]?.az ?? '',
        source: 'headword',
      })
    }
  }

  // Pass 2: every OTHER topic's example sentences that contain a known
  // headword (cross-topic usage). Skip a topic re-matching its own
  // headword sentence (already captured in Pass 1).
  const allWords = [...index.keys()]
  for (const topic of vocabTopics) {
    for (const { word, sentences } of topic.words) {
      for (const otherTopic of vocabTopics) {
        if (otherTopic.topicId === topic.topicId) continue
        for (const otherWordEntry of otherTopic.words) {
          for (const sentence of otherWordEntry.sentences) {
            if (containsWord(sentence.en, word)) {
              addEntry(word, {
                topicId: otherTopic.topicId,
                topicName: otherTopic.title,
                sentence: sentence.en,
                sentenceAz: sentence.az,
                source: 'example',
              })
            }
          }
        }
      }
    }
  }

  // Pass 3: Active Production answers containing a known headword.
  for (const file of productionFiles) {
    for (const section of file.sections) {
      for (const prompt of section.prompts) {
        for (const word of allWords) {
          if (containsWord(prompt.answerEn, word)) {
            addEntry(word, {
              topicId: file.fileId,
              topicName: section.topicName,
              sentence: prompt.answerEn,
              sentenceAz: prompt.answerAz,
              source: 'production',
            })
          }
        }
      }
    }
  }

  return index
}
```

```js
// qulaq-as/src/hooks/useContent.js
import { useEffect, useState } from 'react'
import { parseVocabFile } from '../lib/parseVocab'
import { parseProductionFile } from '../lib/parseProduction'

const VOCAB_ID_RE = /^(0[1-9]|[12][0-9]|3[0-3])-/
const PRODUCTION_ID_RE = /^(3[4-9]|4[0-2])-/

function classifyAndParse(fileId, rawText) {
  // A malformed file must not crash the whole app (spec §9) — isolate each
  // file's parse in its own try/catch, skip it, and log which one failed.
  try {
    if (VOCAB_ID_RE.test(fileId)) {
      return { kind: 'vocab', data: parseVocabFile(rawText, fileId) }
    }
    if (PRODUCTION_ID_RE.test(fileId)) {
      return { kind: 'production', data: parseProductionFile(rawText, fileId) }
    }
    return null
  } catch (err) {
    console.error(`qulaq-as: failed to parse ${fileId}.md, skipping it.`, err)
    return null
  }
}

function splitResults(entries) {
  const vocabTopics = []
  const productionFiles = []
  for (const entry of entries) {
    if (!entry) continue
    if (entry.kind === 'vocab') vocabTopics.push(entry.data)
    if (entry.kind === 'production') productionFiles.push(entry.data)
  }
  vocabTopics.sort((a, b) => a.topicId.localeCompare(b.topicId))
  productionFiles.sort((a, b) => a.fileId.localeCompare(b.fileId))
  return { vocabTopics, productionFiles }
}

function loadBuildTime() {
  // Vite bundles every matched file's raw text at build time — no network
  // request at runtime.
  const modules = import.meta.glob('../../content/*.md', {
    query: '?raw',
    import: 'default',
    eager: true,
  })
  const entries = Object.entries(modules).map(([path, rawText]) => {
    const fileId = path.split('/').pop().replace(/\.md$/, '')
    return classifyAndParse(fileId, rawText)
  })
  return splitResults(entries)
}

async function loadRuntimeFetch(fileIds) {
  const entries = await Promise.all(
    fileIds.map(async (fileId) => {
      const res = await fetch(`/content/${fileId}.md`)
      if (!res.ok) throw new Error(`Failed to fetch ${fileId}.md (${res.status})`)
      const rawText = await res.text()
      return classifyAndParse(fileId, rawText)
    })
  )
  return splitResults(entries)
}

// Build-time mode discovers files via import.meta.glob, so it doesn't need
// a filename list. Runtime-fetch mode needs to know what to ask for; reuse
// the build-time glob's *keys* (not eager) just to enumerate filenames
// without bundling their contents twice.
function listContentFileIds() {
  const modules = import.meta.glob('../../content/*.md', { query: '?raw' })
  return Object.keys(modules).map((path) => path.split('/').pop().replace(/\.md$/, ''))
}

/**
 * @param {'build'|'fetch'} mode
 * @returns {{ vocabTopics: Array, productionFiles: Array, loading: boolean, error: Error|null, retry: () => void }}
 */
export function useContent(mode) {
  const [state, setState] = useState({ vocabTopics: [], productionFiles: [], loading: true, error: null })
  const [retryTick, setRetryTick] = useState(0)

  useEffect(() => {
    let cancelled = false

    if (mode === 'build') {
      try {
        const { vocabTopics, productionFiles } = loadBuildTime()
        if (!cancelled) setState({ vocabTopics, productionFiles, loading: false, error: null })
      } catch (err) {
        if (!cancelled) setState((s) => ({ ...s, loading: false, error: err }))
      }
      return () => { cancelled = true }
    }

    // mode === 'fetch'
    setState((s) => ({ ...s, loading: true, error: null }))
    const fileIds = listContentFileIds()
    loadRuntimeFetch(fileIds)
      .then(({ vocabTopics, productionFiles }) => {
        if (!cancelled) setState({ vocabTopics, productionFiles, loading: false, error: null })
      })
      .catch((err) => {
        if (!cancelled) setState((s) => ({ ...s, loading: false, error: err }))
      })

    return () => { cancelled = true }
  }, [mode, retryTick])

  // Runtime-fetch mode's most likely failure is transient (network hiccup,
  // dev server not yet ready) — exposing a retry lets the UI offer a
  // "Yenidən cəhd et" button (spec §9) instead of a dead end.
  function retry() {
    setRetryTick((t) => t + 1)
  }

  return { ...state, retry }
}
```

```js
import { createCard, reviewCard, isDue } from '../lib/srs'

const STORAGE_KEY = 'qulaq-as-state'
const DEFAULT_STATE = {
  heard: {},
  srs: {},
  settings: { dataMode: 'build', rate: 0.85, voiceRepeat: 2 },
}

function loadState() {
  try {
    const raw = window.localStorage.getItem(STORAGE_KEY)
    if (!raw) return { state: { ...DEFAULT_STATE }, hadError: false }
    const parsed = JSON.parse(raw)
    // Merge with defaults so a state saved before a new settings field was

        srs: parsed.srs ?? {},
        settings: { ...DEFAULT_STATE.settings, ...(parsed.settings ?? {}) },
      },
      hadError: false,
    }
  } catch (err) {
    console.error('qulaq-as: could not read saved progress, starting fresh.', err)
    return { state: { ...DEFAULT_STATE }, hadError: true }
  }
}

function saveState(state) {
  try {
    window.localStorage.setItem(STORAGE_KEY, JSON.stringify(state))
  } catch (err) {
    console.error('qulaq-as: could not save progress.', err)
  }
}

function todayStr() {
  return new Date().toISOString().slice(0, 10)
}

/**
 * @returns {{
 *   heard: Record<string, true>,
 *   srs: Record<string, {interval: number, ease: number, due: string, reps: number}>,
 *   settings: {dataMode: 'build'|'fetch', rate: number, voiceRepeat: number},
 *   storageError: boolean,
 *   dismissStorageError: () => void,
 *   markHeard: (key: string) => void,
 *   rateCard: (key: string, rating: 'again'|'hard'|'good'|'easy') => void,
 *   updateSettings: (patch: object) => void,
 *   dueCards: () => string[],
 *   resetAll: () => void,
 * }}
 */
export function useProgress() {
  // Both lazy initializers run loadState() once, on mount only (React
  // guarantees this) — reading localStorage twice at startup is cheap and
  // keeps each piece of state independent and easy to follow.
  const [state, setState] = useState(() => loadState().state)
  const [storageError, setStorageError] = useState(() => loadState().hadError)

  useEffect(() => { saveState(state) }, [state])

  function dismissStorageError() {
    setStorageError(false)
  }

  const markHeard = useCallback((key) => {
    setState((s) => {
      if (s.heard[key]) return s
      const nextSrs = s.srs[key] ? s.srs : { ...s.srs, [key]: createCard(todayStr()) }
      return { ...s, heard: { ...s.heard, [key]: true }, srs: nextSrs }
    })
  }, [])

  const rateCard = useCallback((key, rating) => {
    setState((s) => {
      const existing = s.srs[key] ?? createCard(todayStr())
      const updated = reviewCard(existing, rating, todayStr())
      return { ...s, srs: { ...s.srs, [key]: updated } }
    })
  }, [])

  const updateSettings = useCallback((patch) => {
    setState((s) => ({ ...s, settings: { ...s.settings, ...patch } }))
  }, [])

  const dueCards = useCallback(() => {
    const today = todayStr()
    return Object.keys(state.srs).filter((key) => isDue(state.srs[key], today))
  }, [state.srs])

  const resetAll = useCallback(() => {
    setState({ ...DEFAULT_STATE })
  }, [])

  return { ...state, storageError, dismissStorageError, markHeard, rateCard, updateSettings, dueCards, resetAll }
}
```

```js
// qulaq-as/src/hooks/useSpeech.js
import { useEffect, useRef, useState } from 'react'

function pickVoice() {
  if (!window.speechSynthesis) return null
  const voices = window.speechSynthesis.getVoices()
  if (!voices.length) return null
  return (
    voices.find((v) => /en[-_]US/i.test(v.lang) && /female|samantha|zira|aria/i.test(v.name)) ||
    voices.find((v) => /en[-_]US/i.test(v.lang)) ||
    voices.find((v) => /^en/i.test(v.lang)) ||
    null
  )
}

/**
 * @returns {{
 *   speak: (text: string, opts?: {rate?: number, repeat?: number}) => void,
 *   stop: () => void,
 *   speaking: boolean,
 *   voiceAvailable: boolean,
 * }}
 */
export function useSpeech() {
  const [speaking, setSpeaking] = useState(false)
  const [voiceAvailable, setVoiceAvailable] = useState(false)
  const voiceRef = useRef(null)
  const queueRef = useRef([])

  useEffect(() => {
    if (!window.speechSynthesis) {
      setVoiceAvailable(false)
      return
    }
    voiceRef.current = pickVoice()
    setVoiceAvailable(voiceRef.current !== null)
    const handler = () => {
      voiceRef.current = pickVoice()
      setVoiceAvailable(voiceRef.current !== null)
    }
    window.speechSynthesis.onvoiceschanged = handler
    return () => {
      if (window.speechSynthesis) window.speechSynthesis.onvoiceschanged = null
    }
  }, [])

  function runQueue() {
    if (!queueRef.current.length) {
      setSpeaking(false)
      return
    }
    setSpeaking(true)
    const next = queueRef.current.shift()
    const utter = new SpeechSynthesisUtterance(next.text)
    utter.lang = 'en-US'
    if (voiceRef.current) utter.voice = voiceRef.current
    utter.rate = next.rate
    utter.onend = runQueue
    utter.onerror = runQueue
    window.speechSynthesis.speak(utter)
  }

  function stop() {
    queueRef.current = []
    if (window.speechSynthesis) window.speechSynthesis.cancel()
    setSpeaking(false)
  }

  function speak(text, { rate = 0.85, repeat = 1 } = {}) {
    if (!window.speechSynthesis) return
    stop()
    queueRef.current = Array.from({ length: repeat }, () => ({ text, rate }))
    runQueue()
  }

  return { speak, stop, speaking, voiceAvailable }
}
```

```js
// qulaq-as/src/lib/courseStages.js

function shuffleInPlace(arr, randomFn) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(randomFn() * (i + 1))
    ;[arr[i], arr[j]] = [arr[j], arr[i]]
  }
  return arr
}

function pickDistractors(words, excludeWord, count, randomFn) {
  const pool = words.filter((w) => w.word !== excludeWord)
  shuffleInPlace(pool, randomFn)
  return pool.slice(0, count)
}

/**
 * Stage 1: word -> correct meaning, 4-option multiple choice.
 * @param {Array} words - a topic's words array (parseVocabFile shape)
 * @param {() => number} randomFn
 */
export function buildStage1Questions(words, randomFn = Math.random) {
  return words.map((w) => {
    const distractors = pickDistractors(words, w.word, 3, randomFn)
    const options = shuffleInPlace([w.gloss, ...distractors.map((d) => d.gloss)], randomFn)
    return { prompt: w.word, options, correctIndex: options.indexOf(w.gloss) }
  })
}

/**
 * Stage 2: the word's own first example sentence with the word blanked out
 * (a real collocation-in-context), 3-4 option multiple choice.
 */
export function buildStage2Questions(words, randomFn = Math.random) {
  return words.map((w) => {
    const sentence = w.sentences[0]?.en ?? ''
    const blanked = blankOutWord(sentence, w.word)
    const distractors = pickDistractors(words, w.word, 3, randomFn)
    const options = shuffleInPlace([w.word, ...distractors.map((d) => d.word)], randomFn)
    return { prompt: blanked, options, correctIndex: options.indexOf(w.word) }
  })
}

/**
 * Stage 3: the word's SECOND example sentence (different context from
 * Stage 2), blanked the same way.
 */
export function buildStage3Questions(words, randomFn = Math.random) {
  return words.map((w) => {
    const sentence = w.sentences[1]?.en ?? w.sentences[0]?.en ?? ''
    const blanked = blankOutWord(sentence, w.word)
    const distractors = pickDistractors(words, w.word, 3, randomFn)
    const options = shuffleInPlace([w.word, ...distractors.map((d) => d.word)], randomFn)
    return { prompt: blanked, options, correctIndex: options.indexOf(w.word) }
  })
}

function blankOutWord(sentence, word) {
  const escaped = word.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
  const re = new RegExp(`\\b${escaped}\\b`, 'i')
  return sentence.replace(re, '___')
}
```

```jsx
        <input
          type="range"
          min="0.6"

          step="0.05"
          value={settings.rate}
          onChange={(e) => progress.updateSettings({ rate: parseFloat(e.target.value) })}
        />
      </label>

      <label className="settings-row">
        <span>Söz təkrar sayı</span>
        <select
          value={settings.voiceRepeat}

        >

          <option value={2}>2×</option>
          <option value={3}>3×</option>
        </select>
      </label>

      <div className="settings-row">
        <button onClick={handleReset} className={confirmReset ? 'danger confirm' : 'danger'}>

        </button>
      </div>
    </div>
  )
}
```
